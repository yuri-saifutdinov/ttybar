# ttybar

## Language

- Everything in the repository is written in English: code, identifiers, comments,
  documentation, OpenSpec artifacts, commit messages, PR descriptions.
- Conversation with the user is in Russian.

## Workflow

- Spec-driven development with OpenSpec (`openspec/`, schema `spec-driven`).
- Start a change with `/opsx:propose "<idea>"`, implement with `/opsx:apply`,
  finish with `/opsx:archive`.
